# RAG Knowledge Base

В эту директорию будут помещаться локальные документы (PDF, Markdown, TXT, DOCX), методички, конспекты лекций и учебные материалы курсов.

### Структура и назначение:
1. **Текущий этап**: Локальный источник знаний для встроенного AI-ассистента по курсам.
2. **Следующий этап**: Подключение облачных коннекторов (Google Drive API / Google Drive sync) для автоматической синхронизации базы знаний.

AI-ассистент анализирует материалы из этой папки и формирует ответы на вопросы студентов с точными ссылками на источники.
